# Symbl.ai

> Symbl.ai is a conversation-intelligence platform for understanding and generating insights from human conversations across voice, video, and text. Its developer platform exposed Async, Streaming, Telephony, Conversation and Management APIs plus the Nebula LLM for real-time speech-to-text and conversational insights (action items, topics, questions, follow-ups, sentiment, custom trackers), with first-party SDKs for JavaScript, Web, Python, and Go. Symbl.ai was acquired by Invoca (announced 2025-05-28) and the standalone developer platform has since been DECOMMISSIONED: api.symbl.ai, docs.symbl.ai, platform.symbl.ai, nebula.symbl.ai and integrations.symbl.ai no longer resolve in DNS. The marketing site, pricing page, compliance page, blog, public Postman workspaces and the client SDKs on npm, PyPI and pkg.go.dev remain live.

## Historical API surface (not reachable)
- Base: https://api.symbl.ai
- Auth: POST https://api.symbl.ai/oauth2/token:generate with {type, appId, appSecret} returning {accessToken, expiresIn: 86400}. Called "OAuth 2.0" in the docs, but it is a bespoke JSON credential exchange, not an RFC 6749 grant.
- Async API — upload audio/video/text or a URL for asynchronous processing; optional webhookUrl job callback.
- Streaming API — wss://api.symbl.ai/v1/realtime/insights/{connectionId}
- Subscribe API (Beta) — wss://api.symbl.ai/v1/subscribe/{connectionId}, listen-only, up to 10,000 participants.
- Telephony API — PSTN / SIP dial-in.
- Conversation API — topics, action items, questions, follow-ups, entities, sentiment, transcript, analytics, members, speakers.
- Management API — Trackers and Conversation Groups CRUD.
- Experience API / pre-built UI — hosted summary and trackers-and-analytics experiences.
- Nebula LLM and embeddings.
- Errors: plain JSON with a `message` field; 400/401/403/404/405/409/413/429/500/502/504. No RFC 9457 problem+json.
- Limits: concurrency-based, no rate-limit response headers were ever documented. See rate-limits/symblai-rate-limits.yml.
